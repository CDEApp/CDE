# Size units

## Sizes in templates and filters

`--template` and `--filter` use 1024 for each step.

| Unit | Bytes |
| ---- | ----- |
| `B` | 1 |
| `KB` | 1,024 |
| `MB` | 1,024² |
| `GB` | 1,024³ |
| `TB` | 1,024⁴ |

Units are not case-sensitive. See [Output templates](../commands/find.md#output-templates) and [Filters](../commands/find.md#filters).
